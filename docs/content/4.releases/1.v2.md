## Introduction

This page records the v2 release and its migration path. For a new installation, use the [current guide](/docs/ai-ready/getting-started/installation).

Nuxt AI Ready v2 removes IndexNow support. The release has one breaking change.
If you upgrade from v1 to v3, apply this change first. Then follow the [v3 release notes](/docs/ai-ready/releases/v3).

## ⚠️ Breaking Changes

### IndexNow Removed

The module no longer submits URLs to IndexNow. ([#78](https://github.com/harlan-zw/nuxt-ai-ready/pull/78))
These parts no longer exist:

- The `indexNow` option.
- The `ai-ready indexnow` CLI command.
- The `/{key}.txt` key route and the `/__ai-ready/indexnow` route.
- The IndexNow tracking columns and log table. Schema v2.3 rebuilds without them.

Remove `indexNow` from your Nuxt config. Remove calls to the deleted CLI command and routes.

```ts [nuxt.config.ts]
// Before
export default defineNuxtConfig({
  aiReady: {
    indexNow: true,
  },
})

// After
export default defineNuxtConfig({
  aiReady: {},
})
```

To keep IndexNow submission, use the [IndexNow recipe](/docs/ai-ready/advanced/indexnow). It submits a page from the `ai-ready:page:indexed` Nitro hook when its Markdown changes.

## ✅ Upgrading

```bash
# pnpm
pnpm add nuxt-ai-ready@^2

# npm
npm install nuxt-ai-ready@^2

# yarn
yarn add nuxt-ai-ready@^2
```
