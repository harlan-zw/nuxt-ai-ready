# Screenshots

No article figure is needed: this recipe teaches server code, with no UI controls to locate.
Use dev-browser with the task page `indexnow-refresh` for rendered review.
If DISPLAY is empty, launch with `--headless`.
Keep temporary captures in `~/scratch/indexnow-refresh/`. Close task pages after review.
Check desktop and mobile code overflow, heading hierarchy, navigation, metadata, and links.
A screenshot of the current live page cannot prove a pending branch was deployed.
If adding publication figures later, capture at two source pixels per CSS display pixel and inspect PNG dimensions.
